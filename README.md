# Hub Inútil
Site estático de ferramentas de humor feito com HTML, Tailwind via CDN e JavaScript puro.
As ferramentas brincam com a ideia de resolver problemas que não existem.

## Abrir localmente
Dê duplo clique em `index.html` para abrir a página inicial no navegador.

## Publicar no GitHub Pages
Envie os arquivos para a branch `main`; o workflow publica o conteúdo estático da raiz, sem etapa de build.
No GitHub, em **Settings > Pages**, selecione **GitHub Actions** como fonte de publicação.
